## 🛠️ Część 1: Narzędzia - Supermoce dla Twoich Agentów

### Co to są Narzędzia? (Wersja dla Ludzi)

Wyobraź sobie, że masz pracownika, który jest świetny w pisaniu, ale nie ma dostępu do internetu. To jak dać mu laptop bez WiFi - może pisać, ale nie może szukać informacji! 😅

**Narzędzia** to właśnie te "supermoce" - dodatkowe funkcje, które agenci mogą używać podczas pracy. To jak:

* 🔍 Wyszukiwarka Google dla agenta
    
* 📊 Kalkulator dla agenta
    
* 📁 Dostęp do plików dla agenta
    
* 🌐 Wywołania API dla agenta
    

**W CrewAI:** Możesz dać agentowi narzędzie, a on automatycznie wie, kiedy i jak z niego korzystać. To jak dać pracownikowi telefon i on sam wie, kiedy zadzwonić po pomoc!

Otwórz plik `src/financial_researcher/`[`crew.py`](http://crew.py) i dodaj:

```python
from crewai_tools import SerperDevTool

# Inicjalizacja narzędzia
search_tool = SerperDevTool()
```

**To jak włączenie WiFi w laptopie!** 📶 Teraz masz dostęp do internetu.

### Przypisanie Narzędzia do Agenta

W tym samym pliku, znajdź definicję agenta i dodaj narzędzie:

```python
@agent
def researcher(self) -> Agent:
    return Agent(
        config=self.agents_config["researcher"],
        verbose=True,
        tools=[search_tool],  # ⭐ To jest magia!
    )
```

**Co się dzieje:**

* Agent `researcher` otrzymuje narzędzie `search_tool`
    
* Agent automatycznie wie, że może używać tego narzędzia
    
* Gdy zadanie wymaga wyszukiwania, agent użyje narzędzia!
    

**To jak dać pracownikowi telefon i on sam wie, kiedy zadzwonić!** 📞

## 📋 Krok 3: Konfiguracja Agenta z Narzędziem

Otwórz plik `config/agents.yaml` i zobacz jak wygląda agent z narzędziem:

```yaml
researcher:
  role: >
    Starszy Badacz Finansowy dla {company}
  goal: >
    Badaj firmę, newsy i potencjalne możliwości dla {company} na rok {year}
  backstory: >
    Jesteś doświadczonym badaczem finansowym z talentem do znalezienia
    najbardziej istotnych informacji o {company} na rok {year}.
    Zawsze odpowiadaj po polsku.
  llm: openai/gpt-4o-mini
  tools:
    - search_tool: search_tool  # ⭐ Referencja do narzędzia
```

**Kluczowe elementy:**

* `role` - kim jest agent (jak stanowisko)
    
* `goal` - co ma osiągnąć (jak cel projektu)
    
* `backstory` - kontekst (jak CV)
    
* `llm` - który model AI używa
    
* `tools` - **NOWE!** lista narzędzi, które może używać
    

**Uwaga:** Narzędzie można dodać zarówno w [`crew.py`](http://crew.py) (bezpośrednio) jak i w `agents.yaml` (przez referencję). Oba sposoby działają!

## 🔗 Część 2: Kontekst - Sztafeta Informacji

### Co to jest Kontekst? (Proste Wyjaśnienie)

Wyobraź sobie sztafetę olimpijską 🏃‍♂️➡️🏃‍♀️:

* Pierwszy biegacz biegnie i przekazuje pałeczkę
    
* Drugi biegacz otrzymuje pałeczkę i kontynuuje bieg
    

**Kontekst w CrewAI działa tak samo!**

* Pierwsze zadanie (`research_task`) wykonuje pracę i tworzy wynik
    
* Drugie zadanie (`analysis_task`) otrzymuje ten wynik i używa go do dalszej pracy
    

**Różnica:** W CrewAI to dzieje się **automatycznie**! Nie musisz ręcznie przekazywać "pałeczki" - CrewAI robi to za Ciebie! 🎯

### Dlaczego to Ważne?

**Bez kontekstu:**

* Agent `analyst` nie wie, co znalazł `researcher`
    
* Musisz ręcznie przekazywać informacje
    
* Łatwo o błędy i zapomnienie
    

**Z kontekstem:**

* Agent `analyst` automatycznie otrzymuje wyniki z `research_task`
    
* Wszystko działa płynnie
    
* Mniej błędów, więcej automatyzacji!
    

**To jak różnica między ręcznym przekazywaniem dokumentów a automatycznym systemem pocztowym!** 📮

## 📝 Krok 4: Konfiguracja Zadań z Kontekstem

Otwórz plik `config/tasks.yaml` i zobacz jak działa kontekst:

```yaml
research_task:
  description: >
    Przeprowadź dokładne badanie firmy {company}. Skup się na:
    1. Aktualnym stanie i zdrowiu firmy
    2. Historycznych wynikach firmy
    3. Głównych wyzwaniach i możliwościach
    4. Ostatnich newsów i wydarzeń
    5. Przyszłymi perspektywach i potencjalnych rozwojach

    Upewnij się, że organizujesz swoje wyniki w strukturalnym formacie.
  expected_output: >
    Kompleksowy dokument badawczy z dobrze zorganizowanymi sekcjami.
  agent: researcher

analysis_task:
  description: >
    Analizuj wyniki badań i stwórz kompleksowy raport na temat {company}.
    Twój raport powinien:
    1. Zaczynać się od podsumowania wykonawczego
    2. Zawierać wszystkie kluczowe informacje z badań
    3. Zapewniać przemyślane analizę trendów i wzorów
    4. Być sformatowany w profesjonalnym stylu
  expected_output: >
    Dojrzały, profesjonalny raport na temat {company}.
  agent: analyst
  context:
    - research_task  # ⭐ TO JEST MAGIA!
  output_file: output/report.md
```

**Co się tutaj dzieje:**

1. `research_task` - **bez kontekstu** (to pierwsze zadanie, nie ma poprzednika)
    
    * Agent `researcher` używa narzędzia `search_tool` do wyszukiwania
        
    * Tworzy dokument badawczy
        
2. `analysis_task` - **z kontekstem** `[research_task]`
    
    * Agent `analyst` automatycznie otrzymuje wynik z `research_task`
        
    * Używa tego wyniku do stworzenia raportu
        
    * Zapisuje wynik do `output/`[`report.md`](http://report.md)
        

**To jak automatyczna sztafeta!** 🏃‍♂️➡️🏃‍♀️ CrewAI automatycznie przekazuje "pałeczkę" (wynik) z jednego zadania do drugiego!

## 🎬 Krok 5: Pełny Kod Projektu

### Struktura Plików

```python
financial_researcher/
├── .env                    # SERPER_API_KEY, OPENAI_API_KEY
├── src/
│   └── financial_researcher/
│       ├── config/
│       │   ├── agents.yaml  # Agenty z narzędziami
│       │   └── tasks.yaml   # Zadania z kontekstem
│       ├── crew.py          # Import i przypisanie narzędzi
│       └── main.py          # Uruchomienie
└── output/
    └── report.md           # Wynik końcowy
```

### [`crew.py`](http://crew.py) - Pełny Kod

```python
from typing import List
from crewai import Agent, Crew, Process, Task
from crewai.agents.agent_builder.base_agent import BaseAgent
from crewai.project import CrewBase, agent, crew, task
from crewai_tools import SerperDevTool

# Inicjalizacja narzędzia
search_tool = SerperDevTool()

@CrewBase
class FinancialResearcher:
    """Zespół Badaczy Finansowych"""
    
    agents: List[BaseAgent]
    tasks: List[Task]
    
    @agent
    def researcher(self) -> Agent:
        return Agent(
            config=self.agents_config["researcher"],
            verbose=True,
            tools=[search_tool],  # ⭐ Narzędzie wyszukiwania
        )
    
    @agent
    def analyst(self) -> Agent:
        return Agent(
            config=self.agents_config["analyst"],
            verbose=True,
            # Brak narzędzi - analyst nie potrzebuje wyszukiwać
        )
    
    @task
    def research_task(self) -> Task:
        return Task(
            config=self.tasks_config["research_task"],
        )
    
    @task
    def analysis_task(self) -> Task:
        return Task(
            config=self.tasks_config["analysis_task"],
        )
    
    @crew
    def crew(self) -> Crew:
        return Crew(
            agents=self.agents,
            tasks=self.tasks,
            process=Process.sequential,  # Zadania jedno po drugim
            verbose=True,
        )
```

### [`main.py`](http://main.py) - Uruchomienie

```python
from datetime import datetime
from financial_researcher.crew import FinancialResearcher

def run():
    year = datetime.now().year
    inputs = {
        "company": "Tesla",  # Szablon {company}
        "year": year         # Szablon {year}
    }
    
    FinancialResearcher().crew().kickoff(inputs=inputs)

if __name__ == "__main__":
    run()
```

### Uruchomienie

```bash
crewai run
```

**I to wszystko!** 🎉 CrewAI automatycznie:

1. Wypełnia szablony (`{company}`, `{year}`)
    
2. Wykonuje `research_task` (z wyszukiwaniem!)
    
3. Przekazuje kontekst do `analysis_task`
    
4. Tworzy raport w `output/`[`report.md`](http://report.md)

## 🎯 Kluczowe Różnice: Projekt Debaty vs Projekt z Narzędziami

### Projekt Debaty (Część 1)

* ❌ Brak narzędzi zewnętrznych
    
* ❌ Brak kontekstu między zadaniami
    
* ✅ Prosty przepływ: propose → oppose → decide
    
* ✅ Jeden agent wykonuje wiele zadań
    

### Projekt z Narzędziami (Część 2)

* ✅ Narzędzie wyszukiwania (SerperDevTool)
    
* ✅ Kontekst między zadaniami (`context: [research_task]`)
    
* ✅ Specjalizacja agentów (jeden bada, drugi analizuje)
    
* ✅ Zależności między zadaniami (analysis\_task potrzebuje research\_task)
    

**To jak różnica między debatą w klasie a profesjonalnym zespołem badawczym!** 🎓➡️🔬

## 💡 Tworzenie Własnych Narzędzi (Dla Zaawansowanych)

Możesz stworzyć własne narzędzie! To jak zbudowanie własnego narzędzia w warsztacie. 🔧

### Przykład: Custom Tool

```python
from typing import Type
from crewai.tools import BaseTool
from pydantic import BaseModel, Field

class CalculatorInput(BaseModel):
    """Input schema for CalculatorTool."""
    expression: str = Field(..., description="Wyrażenie matematyczne do obliczenia")

class CalculatorTool(BaseTool):
    name: str = "calculator"
    description: str = "Oblicza wyrażenia matematyczne. Użyj tego narzędzia, gdy potrzebujesz wykonać obliczenia."
    args_schema: Type[BaseModel] = CalculatorInput
    
    def _run(self, expression: str) -> str:
        try:
            result = eval(expression)  # Uwaga: eval jest niebezpieczny w produkcji!
            return f"Wynik: {result}"
        except Exception as e:
            return f"Błąd: {str(e)}"
```

### Użycie Custom Tool

```python
from tools.calculator_tool import CalculatorTool

calculator = CalculatorTool()

@agent
def analyst(self) -> Agent:
    return Agent(
        config=self.agents_config["analyst"],
        tools=[calculator],
    )
```

**Uwaga:** `eval()` jest niebezpieczny w produkcji! To tylko przykład. W prawdziwym projekcie użyj bezpieczniejszej metody obliczeń.

## 🎨 Zaawansowane: Różne Modele dla Różnych Agentów

Możesz przypisać różne modele AI do różnych agentów! To jak zatrudnienie eksperta i stażysty - jeden droższy, ale lepszy, drugi tańszy, ale wystarczający. 💰

### Przykład

```yaml
researcher:
  llm: deepseek/deepseek-chat  # Tańszy, dobry do wyszukiwania
  # ...

analyst:
  llm: openai/gpt-4o  # Droższy, lepszy do analizy i pisania
  # ...
```

**Zalety:**

* ✅ Optymalizacja kosztów (tańszy model do prostszych zadań)
    
* ✅ Optymalizacja jakości (lepszy model do złożonych zadań)
    
* ✅ Elastyczność (każdy agent ma najlepszy model dla swojej roli)
    

**To jak różnica między zatrudnieniem eksperta i stażysty!** 👔➡️🎓

## 🐛 Najczęstsze Błędy (I Jak Ich Uniknąć)

### Błąd 1: "Tool not found"

**Problem:** Narzędzie nie jest zainstalowane lub nie jest zaimportowane

**Rozwiązanie:**

```bash
pip install crewai-tools
```

```python
from crewai_tools import SerperDevTool  # Sprawdź import
```

### Błąd 2: "Context task not found"

**Problem:** W `context` używasz nazwy zadania, której nie ma

**Rozwiązanie:**

```yaml
# ❌ Źle
context:
  - research  # Nie istnieje

# ✅ Dobrze
context:
  - research_task  # Zgodne z nazwą w tasks.yaml
```

### Błąd 3: "API Key not found"

**Problem:** Brak klucza API w `.env`

**Rozwiązanie:**

```python
# .env
SERPER_API_KEY=twój_klucz_tutaj
OPENAI_API_KEY=twój_klucz_tutaj
```

### Błąd 4: Narzędzie nie jest używane

**Problem:** Agent nie rozumie, kiedy użyć narzędzia

**Rozwiązanie:**

* Upewnij się, że `description` w zadaniu jasno wskazuje na potrzebę użycia narzędzia
    
* Sprawdź `description` narzędzia - musi być jasne, kiedy go użyć
    
* Użyj `verbose=True` aby zobaczyć, co agent robi
